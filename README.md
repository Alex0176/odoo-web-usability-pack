# web_usability_pack

Odoo 19 (Community) addon repository.

| Module | Summary |
|---|---|
| [web_usability_pack](web_usability_pack/README.md) | Pager at the bottom, page size and first / last page, undo / redo in forms, jump to missing required fields, unsaved mark in the browser tab, Ctrl+S |

Add this directory and a checkout of [OCA/web](https://github.com/OCA/web)
(branch `19.0`) to the `addons_path` of Odoo and install the module
*Web Usability Pack*.
